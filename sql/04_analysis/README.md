# Analisis bisnis

Jalankan `sales_analysis.sql`, `customer_analysis.sql`, dan `delivery_analysis.sql` setelah view analitik selesai dibuat. Query di setiap file mengacu pada pertanyaan di PRD.

Pembelian ulang dihitung dari pelanggan dengan setidaknya satu pesanan terkirim. Tingkat keterlambatan hanya memakai pesanan terkirim dengan tanggal aktual dan estimasi yang valid. Perbandingan negara bagian atau kategori mensyaratkan setidaknya 100 pesanan yang memenuhi syarat. Untuk definisi dan batas interpretasi, lihat [metodologi proyek](../../docs/methodology.md).
