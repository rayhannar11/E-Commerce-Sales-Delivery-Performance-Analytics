# Validasi KPI

Jalankan `kpi_validation.sql` setelah view analitik dibuat. Pastikan jumlah baris view tingkat pesanan sama dengan jumlah `order_id` unik, query pelanggaran key tidak mengembalikan baris, dan total harga item pesanan terkirim sama dengan nilai pada model.

Periksa juga cakupan pembayaran dan ulasan serta jumlah pesanan dengan beberapa baris ulasan sebelum menafsirkan hasil perbandingan rating.
